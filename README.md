# PentaQuest - Backend

Questo repository contiene il backend di **PentaQuest**, un RPG tattico a turni sviluppato come progetto universitario per il corso di **Ingegneria e Sicurezza del Software** (A.A. 2022/2023) presso la Facoltà di Informatica dell'Università degli Studi di Palermo.

Il backend è costruito con **Java 17**, **Spring Boot** e **MongoDB**, ed espone una REST API utilizzata dal frontend per il salvataggio dei progressi di gioco e la generazione procedurale dei nemici per stage.
